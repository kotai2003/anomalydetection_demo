# AI異常検知：閾値と評価指標の説明アプリ

AI外観検査（良品学習型の異常検知）における **異常スコア・閾値・評価指標** を、
統計や機械学習に詳しくない製造現場のエンジニアにも直感的に理解してもらうための
教育用 Streamlit アプリです。

同じ OK / NG のスコア分布に対して閾値を動かすと、混同行列・各指標・ROC/PR/F1 曲線が
**すべて連動して変化する** ことを、一つの画面で見せることを目的にしています。

さらにタブ④では、**「その成績は何枚で測ったのか」** を扱います。同じ検出器でも
評価枚数が少ないと閾値も評価値も大きくぶれ、しかも良く見える方向に偏ることを
反復抽出で実測し、最後に **必要な評価枚数を品質要求から逆算** します。

**公開版**: <https://anomalydetectiondemo.streamlit.app>

> ※ 表示されるデータはすべてアプリ内で生成する疑似データです。実案件のデータは含みません。

## 画面構成

| タブ | 内容 |
|------|------|
| ① 閾値とは何か | OK/NG の異常スコア分布・散布図・閾値スライダー |
| ② 混同行列と評価指標 | 混同行列（TN/FP/FN/TP）と Recall / Specificity / Precision / Accuracy / F1 |
| ③ ROC / PR / F1 曲線 | 3 つの評価曲線と、閾値の決め方（F1最大・見逃しゼロ優先・過検知率上限・コスト最小化・手動） |
| ④ 少数サンプルの問題 | 母集団からの反復抽出。閾値・評価値のばらつき、「見逃しゼロ」の信頼性、必要サンプル数の逆算 |
| 📖 使い方 | 操作マニュアル（タブ内埋め込み／別ウィンドウ表示） |

判定規則は全体を通して **「異常スコア ≥ 閾値 → NG 判定」** で統一しています。

### タブ④について

タブ①〜③が「1 回測った結果」を見るのに対し、タブ④だけは **見ているデータが違います**。
その手前に「ラインの真の実力（母集団）」を置き、そこから決まった枚数だけ抜き取って、
**そのサンプルだけで閾値を決めて評価する** という現場の手順を何度も繰り返します。

- **母集団を先に提示** … 正解の閾値と真の Recall を見せたうえで、少数の抜き取りが
  それをどれだけ外すかを実測する（現場では手に入らない「答え」を持った状態で検証する）
- **1 回の抜き取りの中身** … 箱ひげ図の点 1 つを開くと、その数枚だけで
  分布 → ROC → 混同行列 → F1 と閾値が決まる過程を追える
- **「Recall 100% と報告された割合」** … 既定設定では、真の Recall 82.5% の検出器を
  良品10枚・欠陥2枚で評価すると 97% の試行が「見逃しゼロ」と報告する
- **必要サンプル数の逆算** … 「見逃し率を何 % 以下と言えれば合格か」から必要な欠陥枚数を、
  「過検知率を ±何ポイントで知りたいか」から必要な良品枚数を算出する
  （見逃し率 5% 以下 → 欠陥 73 枚。必要枚数はロットの大きさでは決まらない）

## ローカルでの実行

```bash
pip install -r requirements.txt
streamlit run app.py
```

ブラウザで `http://localhost:8501` を開きます。

## 技術構成

- **UI**: Streamlit + Plotly
- **計算**: NumPy / SciPy / scikit-learn（ROC・PR・AUC）

```
core/               Streamlit 非依存の計算ロジック（単体で検証可能）
  ├ distributions.py  疑似スコア生成（5形状＋外れ値）
  ├ metrics.py        混同行列・各指標（分母 0 は NaN）
  ├ curves.py         閾値スイープ・ROC/PR/AUC・閾値決定 5 モード
  ├ sampling.py       母集団プールからの反復抽出・条件別サマリ
  └ intervals.py      Wilson 信頼区間・3の法則・必要サンプル数の逆算
ui/                 UI 層（タブ 1 枚 = 1 モジュール。図もそのタブが持つ）
  ├ theme.py          配色・フォント
  ├ sidebar.py        操作パネルと全タブ共通データ
  └ tab_*.py          各タブ
app.py              エントリポイント（組み立てのみ）
static/manual.html  操作マニュアル（別ウィンドウ表示にも使用）
```

## デプロイ

[Streamlit Community Cloud](https://streamlit.io/cloud) から、このリポジトリの
`app.py` をメインファイルに指定して公開できます。GPU 不要です。

マニュアルの別ウィンドウ表示には静的配信が必要なため、`.streamlit/config.toml` で
`enableStaticServing = true` を設定しています。
